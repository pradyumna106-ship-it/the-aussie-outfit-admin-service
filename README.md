# the-aussie-outfit-admin-service

## Overview

Admin service for The Aussie Outfit e-commerce platform.

## Features

- Admin authorization
- Banner management
- Coupons management
- generate Sales Report management

## Setup

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure environment variables.
4. Start the service:
   ```bash
   npm start
   ```

## Scripts

- `npm install` - Install dependencies.
- `npm start` - Run the application.
- `npm test` - Run tests (if available).
- `npm run dev` - Run and auto-restart application.
